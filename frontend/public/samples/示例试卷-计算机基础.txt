计算机基础知识测验

一、选择题（每题10分，共40分）

1. 在计算机中，1KB等于多少字节？
A. 1000字节
B. 1024字节
C. 512字节
D. 2048字节
答案: B
解析: 1KB = 2^10 = 1024字节，这是计算机存储的基本换算单位。

2. 以下哪种编程语言是解释型语言？
A. C语言
B. Java
C. Python
D. C++
答案: C
解析: Python是典型的解释型语言，代码逐行解释执行，无需预编译。Java虽然也有解释执行的特性，但需要先编译成字节码。

3. HTTP协议默认使用的端口号是？
A. 21
B. 22
C. 80
D. 443
答案: C
解析: HTTP默认端口80，HTTPS默认端口443，FTP默认端口21，SSH默认端口22。

4. 以下哪个不是关系型数据库？
A. MySQL
B. PostgreSQL
C. MongoDB
D. Oracle
答案: C
解析: MongoDB是文档型NoSQL数据库，而MySQL、PostgreSQL、Oracle都是关系型数据库。

二、填空题（每题15分，共60分）

5. HTML中，用于创建超链接的标签是____。
答案: <a>
解析: <a>标签（anchor）用于创建超链接，通过href属性指定链接目标。

6. JavaScript中，用于声明常量的关键字是____，声明变量的关键字是____。
答案: const, let
解析: ES6引入了const用于声明常量（不可重新赋值），let用于声明块级作用域变量。

7. Git中，将本地更改推送到远程仓库的命令是____。
答案: git push
解析: git push命令用于将本地分支的更新推送到远程仓库对应分支。

8. CSS中，设置元素水平居中的常用方法是设置____属性为auto。
答案: margin
解析: 对于块级元素，设置margin: 0 auto或margin-left: auto; margin-right: auto可实现水平居中。
